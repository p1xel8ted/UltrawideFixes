## ❗Notes

- Don't update BepInEx or Doorstop. They're configured to load extra runtime DLLs that the game's stripped build needs - replacing them stops the game from starting.
- This pack is the right BepInEx setup for any mod you install for this game. If another mod's instructions tell you to install its own pack, skip that step - it'll break this one.

## Features
Tested against Steam version @ 21:9 and 32:9

- Max aspect unlocked
- Native resolution added to in-game resolution list, sorted to top
- UI scaling corrected
- Fullscreen overlay aspect corrected
- Skip intros and press-any-key
- FPS slider cap raised to 500
- Configurable FOV slider range
- Control post-processing (settings are auto-generated)
- Game input blocked while configuration menu is open

## Installation
- Grab the latest release from below.
- Extract the contents of the release zip into the game directory. (e.g. **`steamapps\common\MOUSE`** for Steam on Windows).

### Steam Deck/Linux/MacOS Additional Instructions
**You do not need to do this if you are using Windows!**
- Open up the game properties in Steam and add `WINEDLLOVERRIDES="winhttp=n,b" %command%` to the launch options.
